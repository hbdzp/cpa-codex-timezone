使用提示

Codex CLI 会在请求中附带：

<environment_context>
  <current_date>2026-10-12</current_date>
  <timezone>America/Los_Angeles</timezone>
</environment_context>

插件会把这两项替换成上面设置的时区。普通 OpenAI SDK 请求没有这段内容，可以开启“缺少时注入”，在请求末尾追加一条 developer 消息说明当地时间。
